# PokeGuía

PokeGuía es una aplicación web desarrollada con React y Vite que proporciona información sobre Pokémon, incluyendo generaciones, tipos, batallas y una Pokédex interactiva.

## Características

- **Generaciones**: Explora los Pokémon por generación.
- **Tipos**: Descubre los diferentes tipos de Pokémon y sus características.
- **Batallas**: Simula batallas entre Pokémon.
- **Pokédex**: Consulta información detallada de cada Pokémon.
- **Inicio**: Página principal con una introducción a la aplicación.

## Tecnologías utilizadas

- **React**: Biblioteca para construir interfaces de usuario.
- **Vite**: Herramienta de desarrollo rápida para proyectos modernos de frontend.
- **React Router DOM**: Manejo de rutas en la aplicación.
- **TailwindCSS**: Framework de CSS para estilos rápidos y personalizados.
- **ESLint**: Herramienta para mantener un código limpio y consistente.
